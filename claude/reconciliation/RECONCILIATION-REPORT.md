# Reconciliation findings and coverage

178 catalog rows reconcile 122 historical User blocks, seven tool-answer groups, later direct recovery requests and latest Build 301 phone feedback. Every legacy B1–B195 description (196 rows, duplicateB177) maps to current acceptance/scope. No source or old documentation was deleted; original raw history is byte-identical and replaced active docs have archived copies.

The original plan mixed historical architecture with current status. Per-episode jobs, playback phases, chapter editing, Station manual order, backup/history and decoded video already have implementation/evidence, while full phone/model/background/parity/quality acceptance remains open. The rebuilt catalog keeps those distinct. Most old “done” labels were insufficient to close a current requirement.

The most material gaps are selected-model/readiness and library parity, four-row comparison versus unpublished one-selector draft, hanging/failed phone model tests, expanded sound-sheet space/glass and unequal Activity controls, transactional catalogue corruption/save failures,16 failed Reader fixtures, and incomplete full destination/device/data/publishing/capability acceptance. The plan assigns all active requirements to dependencies and gates.
